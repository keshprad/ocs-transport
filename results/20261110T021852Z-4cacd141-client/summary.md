Message sizes are per path. Bandwidth trials run all paths concurrently; combined values sum native per-path averages within each trial before computing medians.
All listeners are ready before connectors launch in a batch. Native sample windows are independent; this is a sum of concurrent averages, not a shared-clock measurement. Per-host launch skew is saved in bandwidth-combined.csv.
Latency runs one path at a time with the others idle, and is never summed.

Cells show median across repetitions [minimum–maximum]. Bandwidth is Gbit/s; latency is µs.
Latency summarizes perftest t_typical (half round-trip); it is not an independently measured one-way completion time.

Bandwidth timing after native warm-up: 5s start margin + 10s measured + 5s end margin per run (-D 20 -f 5).
